# 🏦 Bank Loan Analysis Dashboard

## 📌 Project Overview
The **Bank Loan Analysis Dashboard** project focuses on analyzing bank loan data to evaluate loan performance, customer behavior, and risk patterns.  
An interactive dashboard was built using **Power BI** to help stakeholders monitor key financial metrics and make data-driven decisions.

This project is designed for **Associate Data Analyst / Data Analyst (Fresher)** roles.

---

## 🎯 Objectives
- Analyze overall loan performance and growth trends  
- Identify **Good Loans vs Bad Loans**  
- Track key financial KPIs  
- Understand customer behavior based on loan purpose, grade, and employment length  
- Support business decision-making with interactive dashboards  

---

## 📊 Key KPIs
- Total Loan Applications  
- Total Funded Amount  
- Total Amount Received  
- Average Interest Rate  
- Average Debt-to-Income (DTI)  
- Month-to-Date (MTD) and Month-on-Month (MoM) metrics  

---

## 📈 Dashboards
### 1️⃣ Summary Dashboard
- Overall loan performance  
- Good Loan vs Bad Loan comparison  
- Funded amount vs received amount  

### 2️⃣ Overview Dashboard
- Monthly trends of total money received  
- Loan distribution by:
  - Purpose  
  - Home Ownership  
  - Employment Length  
  - Loan Term  

### 3️⃣ Details Dashboard
- Loan-level detailed data  
- Interest rate, installment amount, funded amount  
- Drill-down analysis using slicers  

---

## 🧠 Insights
- Identified high-risk loan grades and sub-grades  
- Found loan purposes contributing the most to revenue  
- Analyzed repayment behavior based on employment length  
- Compared profitability of good vs bad loans

## 🚀 How to Use
1. Download and open the **Power BI (.pbix)** file  
2. Use slicers (State, Grade, Purpose, Loan Status) to filter data  
3. Navigate between **Summary, Overview, and Details** dashboards  
4. Explore KPIs and loan-level insights
